# Laboratório Verboo

Relatório público de uma avaliação prática independente, com dados sintéticos.

Página: https://jeffogranetto.github.io/verboo-laboratorio/

Resultados parciais: não equivalem a aprovação geral nem a certificação de modelos. Cada publicação é uma foto datada.

## Arquivos

- `index.html`: leitura e filtros no navegador.
- `data.json`: resultados selecionados, sem credenciais ou dados de clientes.
- `resultados.csv`: tabela para análise.
- `tarefas.json`: enunciados e gabaritos.

## Publicação

Alterações em branch própria, PR para main e squash. GitHub Pages publica a raiz da main.
